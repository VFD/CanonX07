Assembleur pour Canon X07 + carte memoire 4 Ko
Paru dans la revue Microsystèmes de Janvier 1985
Auteur: J. Outhier

Attention, ce programme est prévu pour un Canon X07 muni d'une extension de memoire de 4 Ko. S'il est pourvu d'une autre extension de memoire, il faudra probablement determiner avec précision l'adresse d'implantation du programme afin qu'il n'interfère pas avec les données de gestion de la memoire.

Le source des codes est fourni dans le fichier code.asm.txt
Le programme d'auto implantation est chargeur2.txt
Le programme d'implantation manuel est Chargeur.txt

Les fichiers fournis sont les suivants:
Chargeur.txt
------------
chargeur à taper dans le X07 permettant la saisie des codes machines "a la main" fournis dans le fichier code.asm.txt avec code de controle en fin de chaque ligne

chargeur2.txt
-------------
Chargeur automatique en un seul fichier (a condition de pouvoir le transférer dans le canon par la liaison serie)

code.asm.txt
------------
Liste des codes sources du programme avec code de controle en fin de chaque ligne.

Readme2.txt
-----------
Fichier de notes brouillon diverses personnelles concernant ce programme.
