# Source X07 Studio


___
## Introduction

Dans ce répertoire vous avez des codes sources écrit via le logiciel **X07-Studio** de **Stéphane SIBUE**.

Celà permet de faire du developpement rapide et de générer du code Basic pour le Canon X07 et ensuite de l'envoyer par le port série.

L'extension "**.x07**" sert au programme, le contenu est de type JSON.\
Charger le dans X07-Studio puis générer le programme BASIC, vous pouvez ensuite l'envoyer au Canon X07.

___
## Installation

Décompresser le fichier **ZIP**.\
Le contenu dois aller dans votre répertoire "**Documents**".\
CF; quand vous lancer **X07-Studio**, ils sont automatiquement créés.

___
## Détournement du programme

**X07-Studio** génère du BASIC.\
Il est donc possible de générer du code pour tout type de BASIC.

Test fait sur :
- Sanyo PHC-25
- EXL100 d'Exelvision
- ...

Par contre, pas d'envoie possible.
