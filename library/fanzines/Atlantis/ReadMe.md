# Fanzine Atlantis

___
## Introduction

Atlantis No 0. Je n'ai pas trouvé d'autre no. Le no 0 (gratuit) date d'Avril 1987.\
Plusieurs page consacré au Canon X-07. Ce magazine est imprimer en A3 recto Verso (Mode livret).\
Issu du club C7 et édition Neptune.

Le PDF est une tentative de retauration, le papier étant jauni par l'age.\
Amélioration prévue plus tard, le principe étant déjà de sauvegarder la publication.

À lire : La consécration du CANON X-07

Neptune est édité par : Editions Neptune.\
Directeur de la publication : André Tonic.
