# Courbes en 3 Dimensions, Gazette D2 (198-)(Club C7)(FR)


___
# Introduction

Le programme BASIC pour Canon X07 trace des courbes en 3 dimensions en permettant
à l'utilisateur de définir une fonction mathématique F(X,Y), de configurer les
paramètres d'affichage (couleurs, taille, plage de valeurs X et Y), puis calcule
les coordonnées 3D de la courbe en utilisant une projection isométrique (avec le
coefficient 0.866) avant d'envoyer les commandes de dessin à une imprimante graphique
via LPRINT. Le programme utilise deux boucles imbriquées pour parcourir la grille
de points et gère les hauteurs (Z) avec un facteur de réduction pour éviter les
débordements.
